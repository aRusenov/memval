## 3. Every metric, with its dimension and capacity

`role` decides whether a metric enters the sum. `v` is its within-dimension weight (2 = primary readout). `n` is the value after normalisation to [0,1].

## 4. Scoring formula

```
  n_m  = normalise(raw_m)                       in [0, 1], 1 = ideal
  D_d  = SUM_m (v_m * n_m) / SUM_m (v_m)        dimension score
  C    = SUM_d (w_d * D_d) / SUM_d (w_d)        over AVAILABLE dimensions
  cov  = SUM_{d available} w_d / SUM_{d intended} w_d
```

Normalisers used: identity (higher-better on [0,1]); `1-x` (lower-better on [0,1]); chance correction `(x-c)/(1-c)`; `x/ref` against a stated attainable maximum; `1/n` for counts-to-criterion; `(budget-n)/(budget-1)` for trials-to-criterion against a protocol budget.
